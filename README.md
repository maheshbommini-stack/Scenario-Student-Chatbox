🤖 Scenario-Based Student Problem Solver

📌 Project Overview

Scenario-Based Student Problem Solver is an interactive chatbot designed to help students describe common academic and college-related problems and receive suitable guidance.

Unlike a traditional FAQ chatbot, the application allows students to type their problem naturally. The system analyzes the message, identifies the possible problem category, asks relevant follow-up questions, and provides a recommended next action.

---

🎯 Objective

The main objective of this project is to demonstrate how conversational systems can use text analysis, keyword-based intent detection, follow-up interaction, and response generation to assist students.

🔍 How It Works

The chatbot follows a conversational text-analysis process:

Student enters a problem
          ↓
Text preprocessing
          ↓
Keyword detection
          ↓
Problem category identification
          ↓
Priority identification
          ↓
Follow-up interaction
          ↓
Recommended action
          ↓
Chatbot response

The application also updates the Problem Analysis panel while the conversation progresses.

---

💬 Example Conversation

Student
